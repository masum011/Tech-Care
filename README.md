# Tech Care

Tech Care is a responsive service booking website built with React and Vite. Customers can book repair and maintenance services online, and booking requests are delivered directly via EmailJS.

## Features

* Responsive design for desktop, tablet, and mobile
* Service booking form
* Email notifications using EmailJS
* WhatsApp contact integration
* Modern UI with Lucide React icons
* Fast and optimized performance with Vite

## Tech Stack

* React 19
* Vite
* EmailJS
* Lucide React
* CSS3

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd tech-care
```

Install dependencies:

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

The application will be available at:

```txt
http://localhost:5173
```

## Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Create production build
npm run preview  # Preview production build
npm run lint     # Run ESLint
```

## Booking Workflow

1. User fills out the booking form.
2. User submits the request.
3. EmailJS sends booking details to the business email.
4. Business receives customer information instantly.
5. Customer can also contact via WhatsApp.
